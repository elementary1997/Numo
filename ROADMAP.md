# Роадмап Numo

Принципы: каждая версия — законченный, пригодный к использованию продукт; данные пользователя неприкосновенны (миграции и бэкапы раньше любых новых фич над данными); новая зависимость или первый сетевой вызов — только через ADR.

Оценка объёма: S — дни, M — 1–2 недели, L — больше.

## v0.2 — Полный контроль над операциями

Цель: закрыть базовые сценарии, без которых приложением нельзя пользоваться каждый день.

- [x] Редактирование операции (тап → sheet с предзаполнением) — **S**
- [x] Поиск по заметкам и фильтры по категории/периоду — **M**
- [x] Пользовательские категории: создание, иконка, цвет, архивирование — **M**
- [x] Адаптивный layout для desktop/планшета: NavigationRail, ограничение ширины контента — **M**
- [x] Бэкап: экспорт и импорт всех данных в JSON-файл — **S**

## v0.3 — Хранилище всерьёз

Цель: фундамент данных, который переживёт годы записей (ADR-0003).

- [x] Миграция на drift/SQLite с автопереносом данных из shared_preferences — **L**
- [ ] Индексы и выборки под поиск/фильтры вместо фильтрации в памяти — **S**
- [x] Widget-тесты ключевых сценариев, coverage-отчёт в CI (55% строк на старте) — **M**

## v0.4 — Бюджеты и планирование

Цель: от «куда ушли деньги» к «сколько можно потратить».

- [x] Бюджеты по категориям на месяц: прогресс, предупреждение при приближении к лимиту — **M**
- [x] Регулярные операции (подписки, зарплата): автосоздание по расписанию — **M**
- [x] Индикатор «безопасно тратить сегодня» на дашборде — **S**
- [ ] Локальные уведомления о превышении бюджета и регулярных платежах — **M** *(перенесено в v1.0: системные уведомления имеют смысл вместе с мобильной полировкой; предупреждения о лимитах уже показываются в приложении)*

## v0.5 — Счета и валюты

Цель: реальная картина финансов, а не одна куча.

- [x] Несколько счетов (наличные, карты, вклады), переводы между ними — **L**
- [x] Мультивалютность и курсы ЦБ РФ (ADR-0007) — **M**
- [x] Суммарный капитал (net worth) и его динамика — **S**

## v0.6 — Импорт и автоматизация

Цель: минимум ручного ввода.

- [x] Импорт CSV-выписок: маппинг колонок, предпросмотр, дедупликация — **L**
- [x] Правила автокатегоризации («ПЯТЕРОЧКА → Продукты») — **M**
- [x] Экспорт отчётов в CSV — **S**

## v0.7 — Приватность и синхронизация

Цель: данные защищены и доступны со всех устройств.

- [x] Блокировка приложения: PIN (соль + SHA-256, ADR-0008) — **M**
- [ ] Биометрия (local_auth) — *после ручной проверки на реальных iOS/Android-устройствах: CI мобильные платформы не собирает* — **S**
- [x] Синхронизация между устройствами через папку облака пользователя (LWW-модель, ADR-0008; E2E не требуется — файл не покидает личное облако) — **L**

## Сквозные направления (в каждом релизе)

- **UI-полировка**: интерактивность графиков (тултипы, выделение сектора), hero-переходы, микроанимации
- **Доступность**: semantics для скринридеров, контраст, масштабирование шрифта
- **Производительность**: холодный старт, плавность списков на тысячах операций
- **Инженерное**: зелёный `make check`, ADR на значимые решения, релизы тегами `vX.Y.Z`
