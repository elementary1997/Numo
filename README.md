# Numo

**Numo** (от лат. *nummus* — монета) — приложение для контроля трат и анализа личных финансов. Знай, куда уходят деньги.

Одна кодовая база — все платформы: **iOS · Android · macOS · Windows · Linux · Web** (Flutter).

## Возможности

- 💜 **Обзор** — общий баланс, доходы и расходы месяца, структура трат (кольцевая диаграмма), последние операции
- 🧾 **Операции** — лента по дням с фильтрами «расходы/доходы», удаление свайпом с отменой
- 📊 **Аналитика** — расходы по дням месяца, топ категорий с долями, переключение месяцев
- ➕ **Быстрое добавление** — кастомная клавиатура суммы, выбор категории, заметка, дата
- 🌗 Тёмная и светлая темы (следуют системной), анимированные графики на CustomPainter

## Стек

| Слой | Технология |
|---|---|
| UI | Flutter, Material 3, Google Fonts (Manrope) |
| Состояние | Riverpod |
| Хранилище | shared_preferences (JSON) за интерфейсом репозитория — далее миграция на drift/SQLite |
| Графики | собственные CustomPainter (donut, sparkline, bars) |

## Запуск

```bash
flutter pub get
flutter run            # на подключённом устройстве/эмуляторе
flutter run -d chrome  # web
flutter run -d macos   # macOS
```

Тесты и статический анализ (то же, что гоняет CI):

```bash
make check
```

При первом запуске приложение наполняется демо-данными, чтобы графики сразу были наглядными — их можно удалить как обычные операции.
