# Интеграция с банками: проработка

Статус: исследование + поэтапный план (2026-08). Цель — полная
аналитика по счетам пользователя с минимумом ручной работы.

## Ландшафт: что реально доступно в РФ

| Канал | Состояние | Вывод |
|---|---|---|
| **Открытые API банков для физлиц** | В РФ Open Banking для третьих сторон фактически недоступен: стандарты ЦБ (Открытые API) внедряются для банков и юрлиц, публичных программ доступа для личных приложений нет | Прямой API-путь закрыт, ждём регуляторику |
| **Неофициальные API** (реверс мобильных приложений) | Работают до первого изменения, нарушают договор оферты, риск блокировки клиента | Не делаем принципиально |
| **Агрегаторы** (аналоги Plaid/Tink) | В РФ живых публичных аналогов для физлиц нет | Мониторим |
| **Tinkoff Invest API** | Официальный, но только брокерские счета | Возможная точка №1 для инвест-счетов |
| **Файлы выписок** | Доступны везде: CSV, XLSX, PDF, OFX | Единственный надёжный канал сегодня |
| **СМС/пуш-парсинг** (Android) | Технически возможно, хрупко, чувствительно к приватности | Кандидат в бэклог мобильной фазы |

## Стратегия Numo

**Этап 1 — покрыть файлы (сделано).** CSV + OFX + XLSX + PDF Сбербанка
через единый пайплайн импорта с автомаппингом и дедупликацией
(ADR-0012). Дедупликация по контент-хэшу делает регулярный импорт
безопасным: одну и ту же выписку можно загружать сколько угодно.

**Этап 2 — убрать ручные шаги (следующий).**
- «Папка выписок»: пользователь указывает папку (например, «Загрузки»
  или папку, куда банк кладёт документы) — Numo при запуске сам
  находит новые файлы выписок, показывает предпросмотр и импортирует
  подтверждённое. Механика повторяет папку синхронизации (ADR-0008).
- Запомненные маппинги: связка «подпись файла → выбранные колонки и
  счёт», чтобы повторный импорт того же банка шёл в один клик.

**Этап 3 — официальные API, когда появятся.**
- Tinkoff Invest API для брокерских счетов (отдельный тип счёта
  «Инвестиции»).
- Открытые API ЦБ РФ — отслеживать статус готовности для сторонних
  приложений; архитектурно готово: банк = ещё один источник,
  наполняющий тот же пайплайн импорта с дедупликацией.

## Принципы (наследуются из ADR-0007/0008/0011)

1. Никаких неофициальных API и передачи банковских паролей третьим
   сторонам — только официальные каналы и файлы пользователя.
2. Любая сетевая интеграция — отдельный ADR, явное согласие, выключатель.
3. Источник данных не важен для остального приложения: всё сводится к
   `Tx` через пайплайн импорта.
