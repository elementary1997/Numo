# 0005. file_selector для экспорта/импорта бэкапа

Дата: 2026-08-24
Статус: accepted

## Context

v0.2 включает бэкап: выгрузку всех данных (операции + категории) в JSON-файл и восстановление из него. Нужны системные диалоги «сохранить файл» и «открыть файл» на всех платформах.

## Decision

Использовать `file_selector` — first-party пакет команды Flutter с поддержкой Android, iOS, macOS, Windows, Linux и web (открытие). Формат бэкапа — версионированный JSON (`{"version": 1, "categories": [...], "transactions": [...]}`), сериализация — та же, что в хранилище.

## Consequences

- Один пакет, поддерживаемый Flutter team, вместо самописных платформенных каналов.
- `getSaveLocation` недоступен на web — экспорт там деградирует с понятным сообщением; полноценный web-экспорт (скачивание) — отдельная задача.
- Версия в формате бэкапа позволит читать старые бэкапы после смены схемы.

## Alternatives considered

- **file_picker (community)** — популярен, но тяжелее и исторически нестабилен на desktop.
- **Только буфер обмена** — без зависимостей, но неудобно и рискованно для больших данных.
- **share_plus** — «поделиться» уместно на мобильных, но не решает выбор места сохранения на desktop.
