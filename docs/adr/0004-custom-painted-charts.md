# 0004. Графики — собственные CustomPainter вместо чартовой библиотеки

Дата: 2026-08-24
Статус: accepted

## Context

Дашборд и аналитика построены на трёх графиках: кольцевая диаграмма, сглаженная линия трат, бары по дням. Дизайн-требование — фирменный вид (зазоры и скруглённые концы секторов, градиентные заливки, анимации появления), который в готовых библиотеках достигается борьбой с их API.

## Decision

Рисовать все графики собственными `CustomPainter` в `lib/widgets/charts.dart` (`DonutChart`, `Sparkline`, `DailyBars`), анимации — `TweenAnimationBuilder`. Новые типы графиков добавлять туда же, чартовые библиотеки не подключать.

## Consequences

- Ноль внешних зависимостей и полный контроль над видом; графики — часть дизайн-системы.
- Интерактивность (tooltips, выделение сектора) придётся писать самим, когда понадобится.
- Порог входа для правок чуть выше: нужно понимать Canvas API.

## Alternatives considered

- **fl_chart** — самая популярная, но кастомизация зазоров/наконечников ограничена, тянет зависимость и свой API-стиль.
- **syncfusion_charts** — мощно, но коммерческая лицензия избыточна для трёх графиков.
