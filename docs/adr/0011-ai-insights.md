# 0011. AI-аналитика: локальные инсайты + Claude по ключу пользователя

Дата: 2026-08-24
Статус: accepted

## Context

Нужна «AI-аналитика по финансам». Свой сервер противоречит модели приложения (без бэкенда, ADR-0008), а полезная аналитика возможна на двух уровнях: детерминированные правила локально и полноценный LLM-разбор.

## Decision

Экран «AI-аналитика» состоит из двух слоёв:

1. **Локальные инсайты** (`lib/data/insights.dart`) — чистые правила без сети: норма сбережений/перерасход, крупнейшая категория, самый заметный рост и снижение к прошлому месяцу, темп трат с прогнозом на месяц, крупнейшая разовая трата, состояние бюджетов. Работают всегда и мгновенно.
2. **Разбор от Claude** (`lib/data/ai_service.dart`) — по ключу Anthropic API, который пользователь вводит сам (хранится локально в shared_preferences, модель по умолчанию `claude-sonnet-5`). Запрос уходит ТОЛЬКО по явной кнопке и после диалога согласия; отправляется агрегированная сводка (суммы по категориям и месяцам, балансы, бюджеты) — заметки операций не покидают устройство.

Это третий разрешённый сетевой вызов (после курсов ЦБ и проверки обновлений); в отличие от них он не бывает автоматическим.

## Consequences

- Без ключа экран полноценно работает на локальных правилах.
- Стоимость запросов несёт пользователь на своём ключе; приложение не проксирует и не логирует данные.
- Формат Anthropic Messages API; смена модели доступна в настройках ключа.

## Alternatives considered

- **Свой прокси-бэкенд с бесплатной квотой** — расходы и ответственность за чужие финансовые данные; противоречит ADR-0008.
- **Локальная LLM** — на desktop возможна, но гигабайты весов и качество ниже; не для MVP этой фичи.
- **Только правила без LLM** — оставлено как базовый слой; LLM добавляет связный разбор и советы, которые правилами не выразить.
