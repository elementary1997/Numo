# 0007. Курсы валют ЦБ РФ — первый сетевой вызов приложения

Дата: 2026-08-24
Статус: accepted

## Context

v0.5 вводит счета в разных валютах. Чтобы показать общий капитал в рублях, нужны курсы. До сих пор приложение было полностью офлайн (принцип в AGENTS.md: сеть — только через ADR).

## Decision

- Источник курсов — официальный дневной XML ЦБ РФ (`https://www.cbr.ru/scripts/XML_daily.asp`): без ключей, без регистрации, государственный источник.
- HTTP-клиент — пакет `http` (first-party Dart team; `dart:io` недоступен на web).
- Курсы кэшируются в shared_preferences на 24 часа; офлайн приложение работает на последнем кэше, а без кэша валютные счета просто не конвертируются (капитал показывается по рублёвым счетам). Ошибка сети никогда не блокирует запуск: обновление курсов асинхронно и не ждётся при старте.
- Никаких других сетевых вызовов это решение не разрешает; телеметрии и аналитики по-прежнему нет.

## Consequences

- Общий баланс с валютными счетами помечается знаком «≈» — конвертация по вчерашнему курсу ЦБ, не биржевая.
- XML ЦБ отдаётся в windows-1251 — парсим регулярным выражением только ASCII-поля (CharCode/Nominal/Value), кириллические названия не используем.
- Тестируется парсер на образце XML; сам сетевой вызов в тестах не выполняется.

## Alternatives considered

- **exchangerate.host и подобные API** — требуют ключ или нестабильны; ЦБ надёжнее для рублёвой базы.
- **Зеркала вида cbr-xml-daily.ru (JSON)** — удобнее, но это третья сторона без гарантий.
- **Ручной ввод курса пользователем** — остаётся возможным неявно (кросс-валютный перевод хранит обе суммы), но для пассивного показа капитала неудобен.
