# 0002. Flutter как единая платформа для всех ОС

Дата: 2026-08-24
Статус: accepted

## Context

Требование продукта — работать на iOS, Android, macOS, Windows, Linux и в вебе с современным, полностью кастомным UI. Ресурс разработки — один человек плюс AI-агенты; поддерживать несколько нативных кодовых баз нереалистично.

## Decision

Использовать Flutter (stable, Material 3): одна кодовая база на шесть платформ, собственный рендеринг даёт одинаковый пиксель-точный UI везде, включая кастомные графики на `CustomPainter`.

## Consequences

- Один код, один CI; desktop-сборки трёх ОС собираются матрицей GitHub Actions.
- Размер бандла больше нативного; для macOS/iOS-сборок нужен macOS-раннер (есть в GitHub Actions).
- Стиль UI не «нативный» для каждой ОС — осознанный выбор в пользу собственного дизайна.

## Alternatives considered

- **React Native + Expo** — сильная мобильная часть, но слабый и фрагментированный desktop (особенно Linux/Windows).
- **Kotlin Multiplatform + Compose** — desktop и Android хороши, iOS-часть Compose менее зрелая, web слаб.
- **Tauri/Electron + PWA** — покрывает desktop/web, но мобильные платформы остаются отдельной разработкой.
