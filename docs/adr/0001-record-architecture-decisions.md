# 0001. Вести Architecture Decision Records

Дата: 2026-08-24
Статус: accepted

## Context

Numo — долгоживущий личный проект, развиваемый в основном AI-агентами под руководством владельца. Причины архитектурных решений теряются между сессиями агентов быстрее, чем в командной разработке.

## Decision

Значимые архитектурные решения фиксируем как ADR в `docs/adr/` по формату Нейгарда (Context / Decision / Consequences / Alternatives). Нумерация сквозная, индекс — `INDEX.md`. Новая зависимость или смена слоя хранения — обязательный повод для ADR.

## Consequences

- Агент в новой сессии восстанавливает «почему так» чтением каталога, а не археологией по git log.
- Небольшой налог на оформление при крупных изменениях.
