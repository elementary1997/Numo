# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/), версии — [SemVer](https://semver.org/lang/ru/).
Записи дублируются в приложении: после обновления показывается «Что нового» (`lib/data/changelog.dart`).

## [1.5.0] — 2026-08-24

### Добавлено
- Автообновление: приложение само скачивает новую версию, подменяет файлы и перезапускается (Windows/macOS/Linux); страница релиза осталась запасным вариантом
- Персонализация: масштаб интерфейса (компактный / стандартный / крупный / очень крупный)

### Изменено
- macOS: приложение больше не в App Sandbox (вне App Store он не нужен) — автообновление и папки работают без ограничений

## [1.4.0] — 2026-08-24

### Добавлено
- Официальные иконки банков и сервисов: Сбер, Т-Банк, Альфа, ВТБ, Газпромбанк, Райффайзен, Озон Банк, Яндекс, WB, МТС, Совкомбанк, Tether
- Персонализация: выбор акцентного цвета приложения (10 вариантов), отдельный блок в настройках
- Папка выписок: Numo при запуске сам находит новые файлы выписок и предлагает импорт

### Изменено
- Список валют сокращён до RUB/USD/EUR

## [1.3.0] — 2026-08-24

### Добавлено
- Выбор валюты прямо при вводе операции: сумма в чужой валюте конвертируется в валюту счёта по курсу ЦБ (исходная сумма сохраняется в заметке)
- Узнаваемые значки брендов: Сбер, Т-Банк, МТС, Озон, Совкомбанк, Яндекс отрисованы как настоящие лого

### Изменено
- Цель с привязанным счётом обновляется сама от баланса счёта — кнопка «Пополнить» осталась только у целей без счёта
- «Бюджеты» переименованы в «Лимиты»
- Убран лишний заголовок на экране AI-аналитики

## [1.2.0] — 2026-08-24

### Добавлено
- Вход по биометрии: Touch ID (macOS), Windows Hello, отпечаток/Face ID (Android/iOS) — как альтернатива PIN
- Брендовые иконки счетов: Сбер, Т-Банк, Альфа, ВТБ, Озон, Яндекс и другие
- Цель можно привязать к счёту: пополнение спрашивает счёт-источник и делает реальный перевод
- «Что нового»: после обновления приложение показывает изменения версии
- «Стереть все данные» в настройках — полный сброс с подтверждением
- Версия приложения в боковой панели

### Исправлено
- macOS: у приложения не было доступа к сети (sandbox) — не работали курсы, обновления и AI
- Windows-сборка с биометрией (несовместимость плагина с новым компилятором MSVC)

### Изменено
- Сумма операции показывается в валюте выбранного счёта
- «Разбор от Claude» → «AI-разбор», «Импорт CSV» → «Импорт выписок»
- Экран блокировки показывает столько точек, сколько цифр в вашем PIN
- Релизные сборки начинаются с чистого состояния — без демо-данных
- Графики перерисованы: подписи на подложках без наложений, градиентные бары, аккуратные отступы
- Горизонтальные списки (категории, счета) теперь листаются мышью на компьютере

## [1.1.0] — 2026-08-24

### Добавлено
- Типы счетов: карта, наличные, вклад, накопительный — с группировкой на экране счетов
- Провайдеры AI-разбора: Claude (Anthropic), Cloud.ru, локальные модели через LM Studio, свой OpenAI-совместимый endpoint
- Импорт PDF-выписок Сбербанка (собственный извлекатель текста из PDF)
- Проработка интеграции с банками (docs/bank-integrations.md)

### Исправлено
- macOS-сборки подписываются ad-hoc; в релиз добавлена инструкция первого запуска (Gatekeeper)

## [1.0.0] — 2026-08-24

Первый релиз: операции, категории, бюджеты, цели, счета с переводами и мультивалютностью (курсы ЦБ), регулярные платежи, импорт CSV/OFX/XLSX, автокатегории, AI-аналитика, PIN, синхронизация через папку облака, тёмная/светлая темы, русский и английский языки, сборки для Windows/macOS/Linux.
