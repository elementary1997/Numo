# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/), версии — [SemVer](https://semver.org/lang/ru/).
Записи дублируются в приложении: после обновления показывается «Что нового» (`lib/data/changelog.dart`).

## [1.2.0] — 2026-08-24

### Добавлено
- Вход по биометрии: Touch ID (macOS), Windows Hello, отпечаток/Face ID (Android/iOS) — как альтернатива PIN
- «Что нового»: после обновления приложение показывает изменения версии
- «Стереть все данные» в настройках — полный сброс с подтверждением

### Изменено
- Экран блокировки показывает столько точек, сколько цифр в вашем PIN
- Релизные сборки начинаются с чистого состояния — без демо-данных
- Графики перерисованы: подписи на подложках без наложений, градиентные бары, аккуратные отступы
- Горизонтальные списки (категории, счета) теперь листаются мышью на компьютере

## [1.1.0] — 2026-08-24

### Добавлено
- Типы счетов: карта, наличные, вклад, накопительный — с группировкой на экране счетов
- Провайдеры AI-разбора: Claude (Anthropic), Cloud.ru, локальные модели через LM Studio, свой OpenAI-совместимый endpoint
- Импорт PDF-выписок Сбербанка (собственный извлекатель текста из PDF)
- Проработка интеграции с банками (docs/bank-integrations.md)

### Исправлено
- macOS-сборки подписываются ad-hoc; в релиз добавлена инструкция первого запуска (Gatekeeper)

## [1.0.0] — 2026-08-24

Первый релиз: операции, категории, бюджеты, цели, счета с переводами и мультивалютностью (курсы ЦБ), регулярные платежи, импорт CSV/OFX/XLSX, автокатегории, AI-аналитика, PIN, синхронизация через папку облака, тёмная/светлая темы, русский и английский языки, сборки для Windows/macOS/Linux.
